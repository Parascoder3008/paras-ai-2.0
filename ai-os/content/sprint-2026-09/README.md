## Production rhythm

Redima has the package ready before Paras's morning block. Paras rehearses the actual demo, records the main segment and useful short openings, and notes any failure honestly. Sanchit receives the same resource and the next-step script before it is mentioned publicly.

No music is necessary. Screen recordings use synthetic data; blur credentials, private contacts and browser tabs. Preserve useful limitations. Never fabricate an output to make a tool look successful.

Audience problem; evidence source; spoken script; demonstration inputs; expected output; failure branch; title options without invented outcome numbers; thumbnail brief; resource; 2–3 short scripts; native LinkedIn insight; X thread/article and image brief; handoff; tested CTA; approval; final asset; published URL.

Store timing after recording. Written time ranges are pacing guides; actual duration must be measured. If a new tool/version claim is added, verify official documentation on the recording day.

# Script review

Read ai-os/agent-context.md and the current content brief. The audience is a service-business owner building a first practical AI-assisted system. Use real demonstrations or clearly labeled synthetic data. Never invent a client outcome or a first-person experience to strengthen a hook.

Review the actual script for: a clear useful promise; a visible result early; one coherent problem; accurate and sourced claims; understandable Hinglish; a reproducible demonstration; realistic limitations; pacing suited to the format; and a resource CTA that matches what exists.

Return the strongest parts, specific confusing or unsupported lines, the highest-value edits, and a revised passage when useful. Optional scores are subjective editorial judgments. Don't assign view probabilities, claim a 9.5 score proves success, or force endless rewrites toward an arbitrary threshold.

Check audience response only after publication using dated channel analytics for comparable topics, formats and traffic sources. Don't invent universal retention or CTR benchmarks.

Publishing readiness additionally needs evidence, asset rights, final export, verified resource delivery and Paras's recorded approval as defined by the content board. Passing this review does not authorize publication.

# Paid Ads

## When to use
Setting up or improving paid ads (Google, Meta, LinkedIn). For Paras: **Meta-first** (Realtor ₹99 event, EC webinars) + client campaigns.

## What I need
Platform · goal (leads/sales/awareness) · budget · target audience.

## Platform selection
| Goal | Best platform | Why |
|---|---|---|
| High-intent leads | Google Search | actively looking |
| B2B decision-makers | LinkedIn | title/company targeting |
| Broad awareness / retargeting | Meta | cheap reach + best pixel |

## Structure
- **Google:** Campaign → Ad Groups (keyword themes, 3-5 kw each) → 2-3 ad variations. Start phrase match + negatives day 1; Maximize Clicks → Target CPA once converting.
- **Meta:** Campaign → Ad Sets (audiences) → 3-5 creatives. Test: 1% lookalike, interest, retargeting.

## Ad copy / creative
- Copy: Headline (keyword+benefit) · proof/specificity · CTA · description (benefit + objection + CTA).
- Meta creative: hook (first 3s) → problem→solution→proof → CTA.

## Optimization
- Weekly: check search terms + add negatives · pause CTR <1% · pause high-CPA audiences · test new variations.
- Monthly: reallocate budget · refresh creative (fatigue ~4-6 wks).
- Metrics: Search CTR >3% good / <1.5% investigate; conv rate >3% / <1%; CPA < ⅓ LTV.
